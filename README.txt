SPRINTHUB - STRATEGIC PROJECT MANAGEMENT PLATFORM
--------------------------------------------------

OVERVIEW:
SprintHub is a premium, full-stack project management application designed with a high-end "Hope Bridge" aesthetic. It empowers teams to manage initiatives, track milestones in real-time, and maintain strategic clarity through advanced data visualization and real-time synchronization.

MISSION:
To provide a sophisticated, professional, and intuitive environment for high-performance organizations to synchronize their tactical work with their strategic vision.

CORE FEATURES:
1. THE COMMAND CENTER (DASHBOARD):
   - Real-time analytics showing total projects, active milestones, success stories, and critical nodes.
   - Strategic visualization using Recharts for task status and priority distribution.
   - Dynamic greetings and activity summaries.

2. GLOBAL INITIATIVES (PROJECT MANAGEMENT):
   - Comprehensive project gallery with visual progress trackers.
   - Detailed project views showing team members, target dates, and impact metrics.
   - Advanced filtering and search capabilities.

3. ACTIVE MILESTONES (TASK MANAGEMENT):
   - Clean, list-based interface for tactical task tracking.
   - Priority badges (High, Medium, Low) for strategic focus.
   - Detailed milestone descriptions and ownership tracking.

4. STRATEGIC BOARD (REAL-TIME KANBAN):
   - Full drag-and-drop workflow visualization using React Beautiful DND.
   - Real-time synchronization powered by Socket.io (no refresh needed).
   - High-fidelity feedback for cross-team collaboration.

5. VOLUNTEER HQ (USER MANAGEMENT & RBAC):
   - Secure Role-Based Access Control (RBAC).
   - Administrator-only view for managing team members and applications.
   - Sophisticated status filtering (Pending, Approved, Rejected).

6. AUTHENTICATION & SECURITY:
   - Secure login and registration with JWT (JSON Web Token) authorization.
   - Password encryption using Bcrypt.
   - Protected routes to ensure data integrity and privacy.

TECHNICAL STACK:
- FRONTEND: React (Vite), Tailwind CSS, Headless UI, Recharts.
- BACKEND: Node.js, Express.js.
- DATABASE: MongoDB (Mongoose).
- REAL-TIME: Socket.io.
- DESIGN: Hope Bridge Design System (Forest Green & Cream palette, Serif typography).

DEPLOYMENT:
- Backend: Deployed as a Web Service (Node).
- Frontend: Deployed as a Static Site.
- Database: MongoDB Atlas (Cloud).
